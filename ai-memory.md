## Work Ethics and Practices (Added: 2025-04-19)

### Avoiding Over-engineering
- Be cautious of implementing complex solutions when simpler ones suffice
- Avoid monkey patching or making unnecessary complex modifications
- When encountering issues that require multiple attempts (5-10 times):
  1. Stop and discuss alternative approaches
  2. Consider that sometimes user-side handling might be more efficient
  3. Accept that some limitations are necessary for better system performance

### Efficient Problem Solving
- Focus on direct, efficient solutions rather than complex workarounds
- Avoid unnecessary transformations (e.g., HEX to HSL conversion)
- Prioritize straightforward solutions that solve the core problem

### Communication and Collaboration
- When stuck on a problem:
  - Pause and discuss alternative approaches
  - Be open about limitations
  - Seek simple, effective solutions
- Maintain clear and direct communication
- Accept that some user-side handling might be necessary for better system performance

### Project-Specific Notes
- This is a solo project, so "commit" includes "push" to keep GitHub updated
- Focus on maintaining clean, efficient code without unnecessary complexity
- Prioritize user experience and system performance over complex technical solutions
