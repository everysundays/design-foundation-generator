# Color Wheel Controller Requirements

## ภาพรวม
ระบบควบคุมสีแบบใหม่ที่ใช้ Color Wheel แทนการใช้ slider แยก เพื่อให้การควบคุมสีมีความเป็นธรรมชาติและแม่นยำมากขึ้น

## User Stories
- ในฐานะนักออกแบบ ฉันต้องการปรับแต่งสีได้อย่างแม่นยำ เพื่อให้ได้สีที่ตรงตามมาตรฐาน ADS
- ในฐานะนักพัฒนา ฉันต้องการดูตัวอย่างการเปลี่ยนแปลงสีแบบ real-time เพื่อให้แน่ใจว่าการเปลี่ยนแปลงถูกต้อง
- ในฐานะผู้ใช้ ฉันต้องการปรับค่าสีได้ทั้งแบบรายค่าและแบบกลุ่ม เพื่อความสะดวกในการทำงาน

## ความต้องการด้านฟังก์ชัน
1. Color Wheel Component
   - แสดง wheel สำหรับเลือก Hue และ Saturation
   - แสดงตำแหน่งปัจจุบันบน wheel
   - จำกัดช่วง Hue ตามประเภทสี
   - แสดง feedback เมื่อ hover หรือ drag

2. Lightness Controller
   - แสดง slider แนวตั้งสำหรับควบคุม Lightness
   - แสดง marker สำหรับแต่ละ scale
   - รองรับการปรับค่าแบบรายค่าและแบบกลุ่ม
   - แสดง preview การเปลี่ยนแปลง

3. Preview System
   - แสดงตัวอย่างสีแบบ real-time
   - มีปุ่ม Apply และ Reset
   - แสดงค่า HSL ที่เลือก

## ข้อจำกัดทางเทคนิค
1. ต้องใช้ HSL เป็นระบบสีภายใน
2. ต้องรักษาความแม่นยำของสีตาม ADS
3. ต้องจัดการกรณีพิเศษสำหรับสี neutral

## Dependencies
- Color Scale Management Feature
- ADS Color Standards
