# References

This folder contains reference files and resources for the design foundation generator project.

## Structure

- `color-scales/` - Examples and references for color scale generation
- `wcag/` - WCAG compliance guidelines and examples
- `design-systems/` - Examples from other design systems
- `screenshots/` - UI/UX reference screenshots

## Usage

Place any reference materials, examples, or documentation that might be helpful for development in the appropriate subfolder. This helps keep the main source code clean while maintaining easy access to reference materials.

## Guidelines

1. Keep reference files organized in appropriate subfolders
2. Include source/attribution for external references
3. Use clear, descriptive filenames
4. Add brief descriptions in subfolder README files
